📦 建立的模塊
───────────────────────────────────────────────────────────

✅ 1. 帳戶數據持久化系統
   📄 文件: src/account-persistence-service.js
   
   功能特性:
   • 自動備份帳戶到 Azure Blob Storage
   • 從 Azure 恢復帳戶數據
   • 備份列表管理和自動清理
   • 自動同步（預設 5 分鐘）
   
   API 接口:
   - initialize()
   - saveAccountsToAzure(accounts, userId)
   - restoreAccountsFromAzure(userId)
   - startAutoSync(userId, callback)
   - listBackups(userId)
   - deleteOldBackups(userId, keepCount)
   - manualSync(accounts, userId)

───────────────────────────────────────────────────────────

✅ 2. 錯誤日誌系統
   📄 文件: src/error-logging-service.js
   
   功能特性:
   • 多級別日誌記錄 (CRITICAL, ERROR, WARNING, INFO)
   • 日誌統計分析（按類型和級別）
   • 上傳日誌到 Azure Cloud
   • 時間範圍查詢功能
   • 本地日誌快取（最多 1000 條）
   
   API 接口:
   - logError(type, message, stack, metadata)
   - logWarning(type, message, metadata)
   - logInfo(type, message, metadata)
   - uploadLogs(userId)
   - getLocalLogs(filterType, limit)
   - getLogStatistics()
   - getLogsByTimeRange(startTime, endTime)
   - clearLocalLogs()
   - backupAndClear(userId)

───────────────────────────────────────────────────────────

✅ 3. 用戶認證系統
   📄 文件: src/authentication-service.js
   
   功能特性:
   • 密碼強度驗證（8字符+ 大小寫+數字+特殊符號）
   • 帳戶管理（建立、登入、登出）
   • 會話管理（30分鐘超時）
   • 暴力攻擊防護（5次失敗後鎖定15分鐘）
   • 雙因素認證（OTP）
   • 密碼更改和重置功能
   • 會話撤銷功能
   
   API 接口:
   - createAccount(username, password, email)
   - login(username, password, deviceId)
   - logout(sessionId)
   - validateSession(sessionId)
   - changePassword(username, old, new)
   - resetPassword(email)
   - enableTwoFactor(username)
   - verifyOTP(secret, code)
   - validatePasswordStrength(password)
   - getSessions(username)
   - revokeAllSessions(username)

───────────────────────────────────────────────────────────

✅ 4. 數據同步系統
   📄 文件: src/data-sync-service.js
   
   功能特性:
   • 自動同步（預設 10 分鐘）
   • 操作隊列化 (CREATE, UPDATE, DELETE)
   • 智能數據合併
   • 隊列批處理
   • 衝突解決策略
   • 同步狀態監控
   
   API 接口:
   - initialize()
   - startAutoSync(userId, callback)
   - stopAutoSync()
   - syncData(userId, localData)
   - queueSync(userId, operation, data)
   - processSyncQueue()
   - getSyncStatus()
   - getQueuedOperations()
   - clearQueue()

───────────────────────────────────────────────────────────

✅ 5. 通知系統
   📄 文件: src/notification-service.js
   
   功能特性:
   • 實時通知發送
   • 多種通知類型（成功、錯誤、警告、信息、安全）
   • 帳戶事件通知
   • 同步事件通知
   • 系統事件通知
   • 通知統計分析
   • 已讀/未讀狀態管理
   
   API 接口:
   - sendNotification(type, title, message, metadata)
   - success(title, message, metadata)
   - error(title, message, metadata)
   - warning(title, message, metadata)
   - info(title, message, metadata)
   - securityAlert(title, message, metadata)
   - accountEvent(eventType, accountName, details)
   - syncEvent(eventType, details)
   - systemEvent(eventType, details)
   - getNotifications(limit, unreadOnly)
   - markAsRead(notificationId)
   - clearNotification(notificationId)
   - getNotificationStats()

🎓 技術架構
───────────────────────────────────────────────────────────

設計模式:
   • Singleton Pattern (服務實例)
   • Observer Pattern (通知系統)
   • Queue Pattern (同步隊列)
   • Strategy Pattern (衝突解決)

架構層次:
   Renderer Layer  ← IPC Bridge → Main Process Layer → Azure Cloud
   (UI/Events)                    (Services)           (Storage)

關鍵技術:
   • Electron IPC (進程通信)
   • CryptoJS (數據加密)
   • Azure SDK (雲存儲)
   • Node.js (後端運行)
