# 防盜帳號設備管理指南

## 功能概述

本應用程式已增加防盜帳號裝置管理功能，可有效保護您的 Facebook 帳號安全。

## 主要功能

### 1. 🔐 設備綁定與管理
- **自動設備ID生成**：應用程式會自動為每台設備生成唯一的設備ID
- **設備名稱管理**：自動識別設備型號（Windows/Mac + 瀏覽器類型），支持自定義命名
- **已信任設備列表**：查看所有已信任設備及其新增時間

### 2. ⚠️ 異常登入偵測
- **可疑登入警告**：當從未信任的設備嘗試登入時，應用程式會發出警告
- **異常記錄**：所有可疑登入嘗試都會被記錄，包括帳戶名、設備信息和時間戳
- **手動審核**：您可以選擇批准或拒絕可疑設備

### 3. 🔒 帳號鎖定模式
- **強制設備驗證**：啟用此模式後，只有已信任設備才能登入帳號
- **提高安全性**：防止未授權設備訪問您的帳號
- **靈活控制**：可隨時啟用或禁用此功能

## 使用說明

### 首次使用

1. 點擊**「防盜設備管理」**按鈕打開設備安全面板
2. 應用程式會自動註冊目前設備為「已信任設備」
3. 您可以自定義設備名稱以便識別

### 添加新設備

1. 在新設備上登入應用程式
2. 嘗試登入 Facebook 帳號
3. 應用程式會提示「異常登入偵測」
4. 在原設備上開啟設備安全面板
5. 在「可疑登入嘗試」中選擇「信任此設備」

### 移除不信任的設備

1. 打開設備安全面板
2. 在「已信任的設備」中找到要移除的設備
3. 點擊「移除設備」按鈕
4. 確認移除操作

### 啟用帳號鎖定

1. 打開設備安全面板
2. 在「安全設定」部分勾選「啟用帳號鎖定」
3. 點擊「保存設定」
4. 設定立即生效

## 數據存儲

- **設備ID**：存儲在 localStorage 中，唯一標識設備
- **設備安全設定**：包含已信任設備列表和異常登入記錄
- **Azure 備份**：可通過 Azure 存儲備份設備安全設定（可選）

## 安全建議

1. 定期檢查「已信任的設備」列表
2. 如發現不認識的設備，立即移除
3. 在公共設備上避免登入敏感帳號
4. 定期啟用帳號鎖定模式
5. 備份您的設備安全設定至 Azure 存儲

## 故障排除

### Q: 忘記啟用某設備，現在無法登入？
A: 
1. 在已信任的設備上打開應用程式
2. 進入設備安全面板
3. 在「可疑登入嘗試」中批准目前設備

### Q: 如何在多個設備上使用？
A: 
1. 在主設備上禁用「帳號鎖定」模式
2. 在其他設備上登入
3. 在主設備上批准這些設備
4. 全部設備都信任後，啟用「帳號鎖定」

### Q: 設定丟失怎麼辦？
A: 
1. 連接到 Azure 存儲
2. 使用「恢復」功能還原最新備份
3. 重新加載應用程式
